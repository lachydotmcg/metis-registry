# PowerPoint (pptx)

Use this skill any time a .pptx file is involved, as input or output.

## When to use
- Build slide decks, pitch decks, presentations.
- Read/parse/extract text from a .pptx (even if the text is used elsewhere).
- Edit existing decks; work with layouts, speaker notes, templates.

## How
Use python-pptx to build/edit slides. Keep the template's look when editing. Return the output path.
