# Spreadsheets (xlsx)

Use this skill when a spreadsheet (.xlsx/.csv/.tsv) is the primary input or output.

## When to use
- Read/edit/fix an existing spreadsheet (add columns, compute formulas, format, chart).
- Create a new spreadsheet from data.
- Clean messy tabular data into a proper sheet.

## How
Use openpyxl/pandas. Preserve existing sheets/formatting when editing. The deliverable must be a spreadsheet file; report its path.
