# PDF Toolkit (pdf)

Use this skill for anything involving PDF files.

## When to use
- Extract text/tables from PDFs, OCR scanned PDFs.
- Merge, split, rotate, watermark pages.
- Fill PDF forms; encrypt/decrypt; extract images.
- Create new PDFs from content.

## How
Use pypdf / pdfplumber / reportlab as appropriate. For OCR use a Tesseract-backed step. Always report the output path.
