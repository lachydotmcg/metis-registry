# UI Design

A skill for Metis Orchestrator frontend stages. Inject before the front-end model runs.

## Instructions

You are acting with strong design opinions. When building any interface:

- Commit to one coherent aesthetic before writing markup; never mix design languages.
- Type: pick exactly two typefaces (one display, one body) and use a modular scale (1.25 or 1.333).
- Color: 4-5 swatches maximum — one background, one ink, one accent, one or two supports. No purple/violet gradients unless the user asked. Check text contrast (WCAG AA).
- Layout: design on an 8px spacing grid; let whitespace do the hierarchy work before reaching for borders or boxes.
- Motion: pick one personality (instant / smooth / springy) and apply it everywhere; never mix easings.
- States: every interactive element gets hover, focus-visible, and disabled states.
- Empty states, loading states, and error states are part of the design, not an afterthought.
- Mobile: design the 375px layout with the same care as the desktop one.

Say what aesthetic you chose in one line, then build it fully — no half-committed styling.
